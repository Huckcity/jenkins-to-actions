    What this converter does
    
    
    Paste a .circleci/config.yml and you get a GitHub Actions workflow plus a list of everything that did not map cleanly. Executors are resolved, reusable commands are expanded inline with their parameters, and every workflow becomes a set of jobs with needs. Conversion runs entirely in your browser; nothing is uploaded.
    
    
    Orbs are not fetched. The commonest orb steps (node, python, docker, aws-cli, codecov, slack, browser-tools) are mapped; others become TODO steps that fail loudly with the original quoted.

    Things to check by hand
    
    
      
      
    • Orb jobs (node/test, aws-ecr/build-and-push-image …) are not expanded; write the equivalent job from the Marketplace action.
      • 
      
    • Secondary containers were reachable on localhost in CircleCI; on GitHub they are reachable by service name from a container job.
      • 
      
    • Dynamic config (setup: true) cannot be converted; convert the generated config instead.
      • 
    
    

    
    FAQ
    
    
    Is my config uploaded anywhere?
    
    
    No. The converter runs in your tab. Read circleci.js on GitHub.
    
    
    Can I run this from the command line?
    
    
    Yes: npx jenkins-to-actions convert .circleci/config.yml.
