What this converter does

Paste an azure-pipelines.yml and you get a GitHub Actions workflow plus a list of everything that did not map cleanly. Stages, jobs, deployment jobs, steps and more than fifty built-in tasks are handled. Conversion runs entirely in your browser; nothing is uploaded.

Templates (- template:, extends:) are not fetched: paste the expanded pipeline, or convert each template separately. Anything without a clean equivalent becomes a TODO step that fails loudly.

Things to check by hand

  • Service connections have no equivalent. Each becomes a set of secrets (or an OIDC login) you create in GitHub.
  • Artifact staging. $(Build.ArtifactStagingDirectory) becomes _artifacts in the workspace; create it before writing to it.
  • Runtime expressions ($[ ... ]) are left as-is for you to translate.

FAQ

Is my pipeline uploaded anywhere?

No. The converter runs in your tab. Read azure.js on GitHub.

How does this compare with GitHub Actions Importer?

Actions Importer connects to Azure DevOps and converts in bulk, including task mappings you configure. This page needs nothing installed and no connection. The same converter runs as npx jenkins-to-actions convert azure-pipelines.yml.
