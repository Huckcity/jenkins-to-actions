What this converter does

Paste a bitbucket-pipelines.yml and you get a GitHub Actions workflow plus a list of everything that did not map cleanly. YAML anchors in definitions are resolved; every pipeline section (default, branches, pull-requests, tags, custom) becomes a chain of jobs with the right trigger condition. Conversion runs entirely in your browser; nothing is uploaded.

Common Atlassian pipes are mapped to Marketplace actions; others become TODO steps that fail loudly with their variables quoted.

Things to check by hand

  • Repository and deployment variables set in Bitbucket must be recreated as GitHub variables or secrets.
  • Condition changesets become notes; use on.push.paths or dorny/paths-filter.
  • Runner size (size: 2x) has no direct equivalent; pick a larger hosted runner if memory matters.

FAQ

Is my pipeline uploaded anywhere?

No. The converter runs in your tab. Read bitbucket.js on GitHub.

Can I run this from the command line?

Yes: npx jenkins-to-actions convert bitbucket-pipelines.yml.
