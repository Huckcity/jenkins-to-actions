What this converter does

Paste a Jenkinsfile and you get a GitHub Actions workflow plus a list of everything that did not map cleanly. It handles declarative pipelines (pipeline { }) and the common shape of scripted pipelines (node { stage { } }). Conversion runs entirely in your browser; your pipeline never leaves the page, which matters because Jenkinsfiles tend to contain internal hostnames and credential IDs.

The output is a starting point, not a finished migration. Every construct without a clean equivalent becomes a TODO step that fails loudly, so nothing silently disappears. The notes panel tells you which repository secrets to create.

Why one job per stage is the default

It keeps the shape of your pipeline visible in the Actions graph and lets parallel stages and per-stage agents map directly. The cost is that each job starts from a clean runner, so a Build job cannot see what Checkout produced. If your stages pass files to each other, either switch to the single-job layout (stages become named steps in one job) or add upload-artifact/download-artifact between the jobs. Both layouts are offered above; pick the one that needs fewer edits.

Things that never convert automatically

  • Shared library calls (@Library, custom steps). You will see them as TODO steps with the original call quoted.
  • Groovy logic beyond simple branches: loops, maps, string manipulation. Move it into a script in your repository and call that from a run step.
  • Plugin steps such as emailext, slackSend, withSonarQubeEnv. The notes name the Marketplace action that usually replaces each one.
  • UNSTABLE builds. Actions has success, failure, cancelled and skipped; there is no yellow.

FAQ

Is my Jenkinsfile uploaded anywhere?

No. The page is static and the converter is a single JavaScript file that runs in your tab. There is no backend to send anything to. You can check the network tab, or read convert.js on GitHub.

How does this compare with GitHub's Actions Importer?

GitHub Actions Importer is a CLI that connects to your Jenkins server and converts pipelines in bulk, including plugin configuration it can read from the server. It is the right tool for a large estate. This page is for the moment you have one Jenkinsfile in front of you and want a workflow to start from without installing anything or connecting a server.

The output has errors in it.

Every generated workflow is checked against actionlint in this tool's test suite, but your Jenkinsfile may hit a shape the parser does not understand. Email the Jenkinsfile (redact what you need to) and it will become a test case.
