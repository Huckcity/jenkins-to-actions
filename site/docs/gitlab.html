What this converter does

Paste a .gitlab-ci.yml and you get a GitHub Actions workflow plus a list of everything that did not map cleanly. YAML anchors and extends: are resolved first, so hidden .template jobs work. Conversion runs entirely in your browser; nothing is uploaded.

The output is a starting point, not a finished migration. Anything without a clean equivalent becomes a TODO step that fails loudly, and the notes list the repository secrets and variables you need to create.

Things to check by hand

  • Merge request pipelines. $CI_PIPELINE_SOURCE == "merge_request_event" becomes github.event_name == 'pull_request', and on.pull_request is added.
  • Container registry. $CI_REGISTRY_IMAGE points at ghcr.io/owner/repo with GITHUB_TOKEN; add permissions: packages: write.
  • Jobs without an image run directly on the runner, where service containers need published ports:.

FAQ

Is my pipeline uploaded anywhere?

No. The page is static and the converter runs in your tab. Read gitlab.js on GitHub.

How does this compare with GitHub Actions Importer?

Actions Importer is a CLI that connects to your GitLab instance and converts in bulk. This page is for one file at a time with nothing to install. The same converter is available as npx jenkins-to-actions convert .gitlab-ci.yml.
